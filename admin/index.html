Administration du site

Gestion du contenu de Musagara Daniel

Connexion au dépôt

Cette administration met à jour le fichier content.json dans votre dépôt GitHub. Le jeton GitHub est utilisé uniquement dans cet onglet et n'est pas enregistré dans le site. Limitez-le à ce dépôt avec la permission Contents: Read and write.

Important : protégez /admin/* avec Cloudflare Access. N'utilisez pas un mot de passe statique intégré au code du site. Ne partagez jamais votre jeton GitHub.

Modifier les contenus

Le contenu complet est organisé en JSON. Vous pouvez modifier la biographie, les textes de l'entreprise, les expertises, les produits, les réalisations, les formations, les distinctions, les certifications, les actualités, les images et les coordonnées. Conservez les guillemets et les virgules du format JSON.

Renseignez GitHub, puis chargez le contenu.

Ajouter une image au site

Sélectionnez une photo, un logo, une capture d'écran de réalisation ou une image de galerie. Le fichier sera ajouté au dossier assets/ du dépôt. Copiez ensuite son chemin (par exemple assets/nom-image.jpg) dans le champ image correspondant du JSON.

Après l'enregistrement, Cloudflare Pages publie automatiquement la nouvelle version si le projet est connecté à ce dépôt GitHub.
